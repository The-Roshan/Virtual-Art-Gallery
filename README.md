# 🎨 Virtual Art Gallery

## 🚀 Overview
**Virtual Art Gallery** is an elegant and interactive web-based application designed to showcase a curated collection of artwork in a modern, virtual gallery environment. The project provides a seamless browsing experience with themed rooms for Abstract, Nature, and Modern Art. Built with **HTML**, **CSS**, and **JavaScript**, it offers a lightweight, responsive, and visually appealing platform for art enthusiasts.

---

## ✨ Features
- **Themed Gallery Rooms**  
  Organized sections for Abstract, Nature, and Modern Art, each with a curated set of images.

- **Interactive Modal View**  
  Click on any artwork to view an enlarged version in a modal overlay.

- **Responsive Design**  
  Optimized for all devices, from mobile phones to desktop screens, using flexible CSS layouts.

- **Modern Typography**  
  Utilizes the Poppins font from Google Fonts for a clean and professional look.

- **No External Frameworks**  
  Built with vanilla HTML, CSS, and JavaScript for simplicity and performance.

| Technology | Role                              |
|------------|-----------------------------------|
| HTML5      | Structure and layout              |

## 📁 Project Structure
```
virtual-art-gallery/
├── index.html        # Main HTML structure of the gallery
├── styles.css        # Styling for layout, rooms, and modal
├── script.js         # JavaScript for modal functionality
├── art1.jpg          # Placeholder image (user-provided)
├── art2.jpg          # Placeholder image (user-provided)
├── ...              # Additional images (user-provided)
└── README.md         # Project documentation
```

**Note**: Image files (e.g., `art1.jpg`, `art2.jpg`, etc.) are not included in the repository. Users must provide their own images or update the `src` attributes in `index.html` to point to valid image URLs.

## 🛠️ Setup Instructions

### 1. Clone or Download the Repository
```bash
git clone https://github.com/your-username/virtual-art-gallery.git
cd virtual-art-gallery
```

### 2. Add Image Assets
Place your artwork images (e.g., `art1.jpg`, `art2.jpg`, etc.) in the project directory or update the `img` tags in `index.html` with valid image paths or URLs.

### 3. Launch the Project
Open `index.html` in a web browser:
```bash
start index.html      # On Windows
open index.html       # On macOS
```

> ✅ Tip: Use **Live Server** in VS Code for a smoother development experience and to ensure proper loading of assets.

## 🧩 Customization

You can easily customize the gallery to suit your needs:

- **Add New Rooms**: Create additional `<section>` elements in `index.html` with unique `id` attributes and update the navigation menu in the `<header>`.
- **Change Styling**: Modify `styles.css` to adjust colors, fonts, or layout for a different aesthetic.
- **Enhance Interactivity**: Extend `script.js` to add features like image captions, navigation arrows in the modal, or smooth scrolling.
- **Add Animations**: Incorporate CSS animations or transitions for a more dynamic experience.

## 🌍 Deployment

### GitHub Pages
1. Push your code to a GitHub repository.
2. Navigate to `Settings > Pages`.
3. Select the branch and root folder.
4. Visit `https://<your-username>.github.io/virtual-art-gallery/`.

### Netlify / Vercel
- Drag and drop the project folder into the platform dashboard.
- Or connect your GitHub repository for continuous deployment.
